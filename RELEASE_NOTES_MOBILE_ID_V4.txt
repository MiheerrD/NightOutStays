Guest mobile

- Rebuilt Guest Messages for a cleaner mobile conversation layout.

Profile photos
- Guest profile photo upload from Guest Profile.
- Guest profile photo upload also available during ID verification.
- Host profile photo upload added to Host Profile.
- Guest sees Host profile photo in chat.
- Host sees Guest profile photo in chat.

Identity verification workflow
- Guest verification page supports PAN, Aadhaar, Passport and Driving Licence.
- Host verification page supports the same document types.
- Documents are stored in a private identity-documents bucket.
- Profile photos are stored separately in a public profile-photos bucket.
- Admin Verifications page added for approve/reject workflow.
- Booking verification status updates when Admin verifies/rejects a Guest booking document.
- Guest/Host account verification status is tracked.
- Admin gets a pending verification count in navigation.

Important: automated government-document authenticity/name matching is NOT enabled yet.
The schema is provider-ready (provider, provider_reference, extracted_name, name_match_score,
authenticity_status). Connect an authorized KYC/DigiLocker/UIDAI-compatible provider before treating
an uploaded image/PDF as automatically verified.
